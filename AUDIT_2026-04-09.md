# AXIS Platform Audit — 2026-04-09

## 1. SEGURANCA: Rotas sem withTenant() (CRITICO)

**24 rotas com resolucao manual de tenant** — padrao quebrado para multi-tenant.
Essas rotas usam `SELECT id FROM tenants WHERE clerk_user_id = $1 LIMIT 1` em vez de `withTenant()`, o que ignora o cookie `axis_active_tenant` e pode pegar o tenant errado.

### Rotas clinicas (PRIORIDADE MAXIMA):
| Rota | Risco |
|------|-------|
| `/api/analyze-clinical` | Analise clinica pode cruzar tenants |
| `/api/suggestions` (GET) | Sugestoes de outro tenant podem vazar |
| `/api/suggestions/[id]/decide` | Decisao clinica pode afetar tenant errado |
| `/api/transcribe` (POST) | Transcricao pode ser associada a tenant errado |
| `/api/transcribe/status/[jobId]` | Status de job pode vazar cross-tenant |
| `/api/chat-ana` (TCC) | Chat com ANA pode acessar dados errados |
| `/api/aba/chat-ana` (ABA) | Idem para ABA |
| `/api/tdah/chat-ana` (TDAH) | Idem para TDAH |
| `/api/audit` | Logs de auditoria podem misturar tenants |
| `/api/stats` | Estatisticas podem agregar cross-tenant |

### Rotas de usuario/infra (prioridade alta):
| Rota | Risco |
|------|-------|
| `/api/user/profile` | Perfil pode retornar tenant errado |
| `/api/user/licenses` | Licencas podem mostrar tenant errado |
| `/api/user/tenant` | Resolucao de tenant inconsistente |
| `/api/user/activate-free` | Ativacao pode afetar tenant errado |
| `/api/push/register` | Push pode ser registrado no tenant errado |
| `/api/push/subscribe` | Idem |
| `/api/tcc/onboarding` | Onboarding com 4x resolucao manual |

### Rotas Google Calendar (prioridade media):
| Rota | Risco |
|------|-------|
| `/api/google/callback` | Token OAuth pode ser salvo no tenant errado |
| `/api/google/disconnect` | Pode desconectar tenant errado |
| `/api/google/status` | Status pode retornar dados errados |
| `/api/google/sync` | Sincronizacao pode misturar calendarios |
| `/api/google/watch` | Webhook pode monitorar tenant errado |

**Recomendacao:** Migrar todas para `withTenant()` do `src/database/with-tenant.ts`. Prioridade: rotas clinicas primeiro.
